## 📖 About This Repository

A collection of **28 hands-on cybersecurity projects** and **12 weekly Blue Team internship reports**, organised in three tracks that show progression from foundational concepts to infrastructure-based SOC work. Each project includes documentation and screenshot evidence of the workflow and findings.

| Track | What's inside | Count |
| --- | --- | --- |
| [1-Foundational-Projects](1-Foundational-Projects/) | SOC alert triage, phishing investigation, network forensics, vulnerability assessment, network security | 10 projects |
| [2-Blue-Team-Cybersecurity-Internship](2-Blue-Team-Cybersecurity-Internship/) | Cyberster Blue Team internship: weekly technical reports + executive summary | 12 weekly reports |
| [3-Advanced-Cyber-Projects](3-Advanced-Cyber-Projects/) | Infrastructure-based SOC / Blue Team labs | 18 projects |

> 📌 The projects in `1-Foundational-Projects` are concept-building work from the early learning phase; the internship and advanced tracks build on them.
